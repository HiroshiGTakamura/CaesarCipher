# Caesar Cipher Web Tool

A simple web-based tool that encrypts plain text into a Caesar Cipher with a fixed +3 character shift in real-time. 

> ⚠️ **Note:** This is an older learning project built during my early programming journey to practice basic JavaScript, DOM interaction, and conditional logic.

## 🚀 How It Works
- **Fixed Shift Encryption:** Replaces standard A–Z characters (both upper and lowercase) with their counterpart shifted 3 positions forward in the alphabet.
- **Unchanged Characters:** Numbers, symbols, spaces, and special characters pass through unmodified.
- **Real-Time Input:** Uses `onkeyup` event listeners to update the output box as text is typed.

## 🛠️ Built With
- **HTML5:** Semantic structural setup with two textareas for input/output.
- **CSS3:** Custom styles integrated with Eric Meyer's CSS reset.
- **Vanilla JavaScript:** Explicit character substitution logic mapping standard A–Z letters.
